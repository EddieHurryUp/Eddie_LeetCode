- `*.py`：按题号命名的题目代码
- `测试开发实习面试-LeetCode10题清单.md`：面试冲刺清单

## 刷题规范

- 每题包含：核心思路、复杂度、易错点（可写在代码末尾注释）
- 提交信息建议：`feat(leetcode): <题号> <题名>`
- 常用 Git 流程：

```bash
git add .
git commit -m "feat(leetcode): 1 two sum"
git push
```
