## Docker 运行说明

### 1) 构建镜像

```bash
docker build -t eddie-leetcode:latest .
```

### 2) 运行指定题目

```bash
docker run --rm eddie-leetcode:latest python "1刷/1.两数之和.py"
docker run --rm eddie-leetcode:latest python "1刷/20.有效的括号.py"
docker run --rm eddie-leetcode:latest python "1刷/206.反转链表.py"
```

### 3) 挂载本地目录边改边跑

```bash
docker run --rm -it \
  -v "$(pwd)":/app \
  -w /app \
  python:3.12-slim \
  python "1刷/1.两数之和.py"
```
